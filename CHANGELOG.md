# Changelog

## 0.1.0 - 2026-07-17

- Read cards from the active OSRS TCG RuneLite profile without changing its
  saved collection.
- Add solo and shared Bronzeman restrictions for tracked NPCs, items, gathering,
  processing, Farming, Hunter, Slayer, Thieving, and Sailing.
- Mark locked NPCs and items and explain which card is required.
- Add an optional private server for shared unlocks, individual collections,
  pack popups, and Top Trumps.
- Let each server member use either the shared cards or only their own cards.
- Add a full collection album for the shared collection and every approved
  player, with recent cards, search, filters, sorting, copy counts, and foils.
- Rank server members by the total score of their unique OSRS TCG cards.
  Duplicate copies do not add points.
- Show delayed group pack popups with the opener's RuneScape name.
- Keep server sync and OSRS Wiki artwork downloads off until the player enables
  them.
- Add Java 11 builds, tests, privacy checks, and third-party notices.
